# Sales Summary App

## Summary
This is a simple single-page application that fetches sales data from a CSV file and displays the total sales.

## Setup
1. Clone the repository.
2. Open `index.html` in a web browser.

## Usage
The application will automatically fetch `data.csv`, calculate the total sales, and display it on the page.

## Code Explanation
- The HTML file includes Bootstrap 5 for styling.
- A fetch request retrieves the CSV data.
- The sales values are summed and displayed in the `#total-sales` div.
